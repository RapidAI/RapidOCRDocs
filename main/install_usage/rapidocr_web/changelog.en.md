#### 2024-07-08 v0.1.10 update

- Fixed issue [#197](https://github.com/RapidAI/RapidOCR/issues/197).

#### ❤2023-05-20 OCRWeb update

- Added the RapidOCRWeb desktop edition. See the [desktop guide](https://rapidai.github.io/RapidOCRDocs/latest/install_usage/rapidocr_web/usage/).
- Reorganized the repository documentation.

#### 🌹2023-05-14 OCRWeb v0.1.5 update

- Added coordinate-box return values for the GUI edition ([issue #85](https://github.com/RapidAI/RapidOCR/issues/85)).
- Added Base64 input support in API mode.
- See the [API/Web README](https://github.com/RapidAI/RapidOCR/blob/main/ocrweb/README.md).

#### 🏸2023-04-16 OCRWeb v0.1.1 update

- Changed API deployment to use FastAPI.
- Decoupled API mode from the Web interface; install selectively with `pip install rapidocr_web[api]`.
- See the [API/Web README](https://github.com/RapidAI/RapidOCR/blob/main/ocrweb/README.md).
